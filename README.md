# RDDS Customized Store

A separate Vite + React storefront for RDDS Customized. This project is independent of RDDS Digital Solution and uses its own future Supabase project.

## Run locally
1. Install Node.js 20+
2. Run `npm install`
3. Run `npm run dev`

## Current starter features
- Responsive luxury black-and-gold storefront
- Product search and category navigation
- Local cart interactions
- Custom-order brief that opens WhatsApp
- Homepage sections for categories, products, process and contact

## Not connected yet
- Supabase database and storage
- Admin authentication and product/order management
- Payment checkout and order tracking
- Customer accounts
- Live product customizer and image upload

Do not add RDDS Digital Solution credentials here. Create a dedicated Supabase project for RDDS Customized before enabling database features.
